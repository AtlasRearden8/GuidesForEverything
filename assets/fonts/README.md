# Bluu Next

These are the landing page's display fonts.

- **Font:** Bluu Next, by Jean-Baptiste Morizot.
- **Published by:** Velvetyne Type Foundry. See https://velvetyne.fr/fonts/bluu/ and https://open-foundry.com/fonts/bluu-next
- **Source:** https://github.com/velvetyne/BluuNext
- **Licence:** SIL Open Font License 1.1. The full text is in `OFL-BluuNext.txt`.
- **"BluuNext" is a Reserved Font Name.** These files are the original fonts, unmodified, only repackaged as WOFF2.

How the files were made: each `.woff2` was converted from the original `BluuNext-*.otf` with fontTools (`flavor='woff2'`).
No glyphs or names were changed.

| File | Original font |
|---|---|
| `BluuNext-Bold.woff2` | BluuNext-Bold.otf |
| `BluuNext-Bolditalic.woff2` | BluuNext-Bolditalic.otf |
| `BluuNext-Titling.woff2` | BluuNext-Titling.otf |
