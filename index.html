Printing

  • Print at Actual size (100%) on US Letter paper.
  • Color is best: callouts and steps are color-coded.
  • Single- or double-sided both work; chapters start on a fresh page.

Keeping current

AI tools change monthly. Each manual's inside cover says when its facts were checked. If something on screen doesn't match, the product's own docs win.

Add a manual

Each manual is one Markdown file. Copy content/_template.md, write, then run node build.mjs. The PDF, its cover, and this page all update.
